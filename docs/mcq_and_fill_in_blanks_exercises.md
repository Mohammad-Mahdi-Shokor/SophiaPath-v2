# MCQ and Fill in the Blanks Exercises

Multiple-Choice Questions (MCQs) are formatted as interactive option cards within lesson slides, providing immediate automated grading and feedback.
Fill in the Blanks (`fill_code` / `write_line`) exercises break code blocks or sentences into tokenized lines with missing key input fields.
Learners must type the exact syntax, keyword, or value required, reinforcing precise code writing and concept recall.
