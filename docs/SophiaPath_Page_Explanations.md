# SophiaPath Platform: Page & Feature Explanations

---

### 1. Code Snippets & Interactive Playground Execution
In SophiaPath lessons, code snippets are embedded directly within reading materials with syntax highlighting and line numbers.
Learners can interact with these snippets and click a "Run in Playground" button to open an isolated execution dialog (such as the C++ Playground).
Inside the playground, students can edit the source code, provide custom standard input (stdin), compile, and view real-time console output without leaving the browser.

---

### 2. MCQ and Fill in the Blanks Exercises
Multiple-Choice Questions (MCQs) are formatted as interactive option cards within lesson slides, providing immediate automated grading and feedback.
Fill in the Blanks (`fill_code` / `write_line`) exercises break code blocks or sentences into tokenized lines with missing key input fields.
Learners must type the exact syntax, keyword, or value required, reinforcing precise code writing and concept recall.

---

### 3. Course-Specific Exercises (C++ Code Challenge & Cyber Report Analyser)
1. **C++ Code Challenge**: Presents students with a structured problem statement, starter code template, and hidden/visible test cases to test code correctness live.
2. **Cybersecurity Report Analyser**: Asks learners to review raw incident logs, vulnerability reports, or security audit dumps, identifying threats and submitting structured security evaluations.

---

### 4. Interactive Java OOP & UML Playground (CS Labs)
The Computer Science Lab features a dual-view playground for Java Object-Oriented Programming and Unified Modeling Language (UML).
Students visually design class structures, attributes, methods, inheritance, and interface relationships on an interactive canvas.
The system simultaneously generates executable Java code and live UML Class Diagrams, helping learners master OOP architecture interactively.

---

### 5. Software Engineering Labs (Use Case Diagram & Gantt Chart)
1. **Use Case Diagram Visualizer**: Allows software engineering students to visually define actors, system boundaries, use cases, and relationships (include/extend).
2. **Interactive Gantt Chart**: Enables learners to map project work breakdown structures, schedule task timelines, set dependencies, and identify critical path milestones visually.

---

### 6. Cybersecurity Labs (Caesar Cipher Explorer)
The Cybersecurity Labs suite offers hands-on interactive simulations for cryptography, network attacks, and defensive security.
The **Caesar Cipher Explorer** lets users adjust substitution shift values dynamically using an interactive slider while observing live encryption/decryption.
It includes character frequency distribution charts and interactive tools for brute-force cracking and frequency analysis practice.

---

### 7. Philosophy Labs (Trolley Problem Visualizer)
The Philosophy Labs transform classic ethical thought experiments into interactive visual simulations.
The **Trolley Problem Visualizer** renders an animated track layout with switch levers, demographic choices, and branching moral dilemmas.
Learners make decisions under simulated pressure, view immediate outcome stats, and analyze their choices against Utilitarianism, Deontology, and Virtue Ethics.

---

### 8. Socrates Dialogue Chatbot
The Socrates AI Chatbot acts as an interactive philosophical and educational mentor using the classic Socratic Method.
Instead of providing direct solutions, it asks probing, reflective questions that encourage learners to test their assumptions and reason critically.
It supports real-time text and ElevenLabs AI voice synthesis, creating an engaging, conversational learning experience.

---

### 9. Admin Dashboard Pages (Individual Explanations)
1. **Syllabus Editor (Courses Tab)**: Centralized management area to create, edit, order, and organize courses, sections, lessons, and interactive slide components.
2. **User Access Control (Users Tab)**: Allows administrators to inspect registered accounts, view XP/levels, and update user roles (Student, Expert, Moderator, Admin) or course permissions.
3. **Role Applications (Applications Tab)**: A review portal where admins evaluate incoming Expert and Moderator application submissions, including uploaded CVs and rationale.
4. **Security & System Audit Logs (Logs Tab)**: Real-time monitoring hub tracking platform activity, authentication attempts, AI voice generations, and administrative actions.

---

### 10. Syllabus Editor & Bumblebee AI Assistant
The Syllabus Editor enables subject matter experts to construct rich curricula using drag-and-drop sections, lessons, and content blocks (text, code, MCQs, labs).
**Bumblebee AI (AI Auditor)** acts as an intelligent co-pilot for experts during syllabus creation.
It automatically audits course materials against modern industry standards, fetches tech news, flags obsolete topics, and drafts new practice exercises.

---

### 11. Achievements System & Gamified Badges
SophiaPath incorporates a gamified achievements hub to incentivize student engagement and continuous learning.
Learners unlock visual badges, earn experience points (XP), and advance through difficulty tiers (Bronze, Silver, Gold, Platinum).
Milestones track course completion, lab challenge victories, quiz streaks, and forum contributions, all showcased on the user's public profile.

---

### 12. Notification Center & System Alerts
The Notification Center keeps learners updated with real-time platform activity and progress alerts.
It notifies users about new course announcements, instructor feedback, community discussion replies, and role application decisions.
Unread badge counts and categorized alert feeds ensure students never miss important learning events or daily streak reminders.

---

### 13. Course Cheatsheets & Quick Reference Guides
Course Cheatsheets provide students with concise, printable summary cards for rapid revision.
Embedded directly in course headers and reading slides, they summarize key syntax rules, CLI commands, and architectural patterns.
Students can view cheatsheets directly in the browser or download them as PDF/text guides for offline studying.
