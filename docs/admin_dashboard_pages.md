# Admin Dashboard Pages

1. **Syllabus Editor (Courses Tab)**: Centralized management area to create, edit, order, and organize courses, sections, lessons, and interactive slide components.
2. **User Access Control (Users Tab)**: Allows administrators to inspect registered accounts, view XP/levels, and update user roles (Student, Expert, Moderator, Admin) or course permissions.
3. **Role Applications (Applications Tab)**: A review portal where admins evaluate incoming Expert and Moderator application submissions, including uploaded CVs and rationale.
4. **Security & System Audit Logs (Logs Tab)**: Real-time monitoring hub tracking platform activity, authentication attempts, AI voice generations, and administrative actions.
