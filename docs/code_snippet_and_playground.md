# Code Snippets and Interactive Playground

In SophiaPath lessons, code snippets are embedded directly within reading materials with syntax highlighting and line numbers.
Learners can interact with these snippets and click a "Run in Playground" button to open an isolated execution dialog (such as the C++ Playground).
Inside the playground, students can edit the source code, provide custom standard input (stdin), compile, and view real-time console output without leaving the browser.
